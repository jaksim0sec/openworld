# 카엘 항구 · 주민 생활 시뮬레이션 V1

> 2026-11-18. **검증용 첫 생활형 Vertical Slice**. 완성된 마을, 최종 3D 아트, 경제/RPG 플레이 루프로 판단하지 않는다.

## 목적과 기존 구조 영향

월드가 플레이어와 무관하게 움직이도록 첫 사회적 루프를 만든다. 기존 Study 05 하늘·잔디 셰이더, `harbor.js` 커스텀 건축 메시, `movement.js` 지형/벽 충돌을 보존한다. 범용 NPC 프레임워크, LLM 대화, 절차적 도시와 저장 시스템은 만들지 않는다.

- `town.js`: **렌더/DOM 비의존** 주민 6명 정의, 역할·경로·일과, 근무 상태, 소형 입항/시장 재고 사건, 거리·시선·벽 가시성 기반 대화 대상.
- `town_render.js`: 공통형 V1 의복/인체 메시, GPU 인스턴싱, 작업별 팔/다리/짐 애니메이션. 도착 전 부두 화물, 정오 이후 시장 진열물의 위치 변화.
- `movement.js`: 현재 상호작용을 NPC 우선으로 확장, 기존 지역/고목 조사와 벽 충돌 보존, NPC 몸체 회피.
- `scene.js`: 기존 렌더 루프에서 NPC simulation update + 추가 WebGL draw 2개 (주민 1, 물품 1), 작은 지역 시계 표시.
- `index.html`: 스크립트 등록, 제목 및 작은 지역 시계. 다른 고정형 패널은 추가하지 않음.

## 주민·생활

| 인물 | 직업 | 관찰 가능한 일상 |
|---|---|---|
| 네린 | 선적 명부 담당 | 부두 명부 확인·입항 점검·정산 |
| 기오 | 하역 운반 반장 | 부두에서 짐 운반, 창고 이동·회수 |
| 마렌 | 시장 상인 | 아침 진열·낮 판매·마감 |
| 라비 | 수리공 | 공방 수리·현장 점검·정리 |
| 세리안 | 길드 서기 | 의뢰 분류·상담·게시판 정리 |
| 바린 | 순찰대원 | 항구/골목 순찰·야간 경비 |

게임 시계는 1초에 게임 내 2.4분이 지나가며, 플레이어가 움직이지 않아도 주민 일정과 NPC의 작업/이동이 계속된다. 단순 사건: **오전 화물이 부두에 남음 → 정오에 시장 물품 진열 → 밤에 마감**, 마렌/네린의 관련 대사가 시간에 따라 변화한다. 경제 전체를 계산하는 시스템은 아니다.

## 조작·검증

- PC: WASD 이동/마우스 시선, NPC 가까이에서 E로 대화.
- 터치: 왼쪽 조이스틱/오른쪽 시점, NPC 접근하면 '조사' 버튼으로 대화.
- 다른 곳에서 보지 못하는 NPC에게 건물 벽 너머로 대화를 걸지 않도록 시야 차단 확인.
- `node --test tests/*.cjs`: **19개 테스트 통과** (기존 걷기/건물 충돌 포함, NPC 이동·다른 dt 결과·일과·상호작용·골목 충돌 추가).
- Chromium + Xvfb + ANGLE SwiftShader **실제 WebGL2**: 데스크톱 560×340 / 내부 280×170, 에뮬레이션 모바일 360×690 / 내부 180×345. 둘 다 렌더링 및 WebGL 오류 0, JavaScript 오류 0.
- 경량 설정에서 약 242K 삼각형, 10 드로우콜. **SwiftShader 약 6~8FPS는 실기기 GPU 수치가 아님.**
- 브라우저에서 직접 NPC 근처로 이동해 대화 확인, 입항→시장 상태 변화를 120초 시뮬레이션 후 확인, 기존 숲 시점 보존 확인.
- 모바일 에뮬레이션 CDP 실제 터치 이벤트: 조이스틱 약 2.2m 전진, 근접 NPC 조사 버튼으로 네린 대화 확인.

## 미완료/검수 미통과

- V1 NPC는 공통 모델로 의복색/작업 포즈만 구별된다. 목표 아트 스타일의 고품질 최종 에셋 아님. 얼굴, 복장, 동작 연결, 조명·그림자는 후속 아트 검수 필요.
- 경로는 마을 작은 구획에 **수작업 지정한 경유점**. 전체 월드용 navmesh/pathfinder 없음. 건물 안팎의 충돌·동선은 단순 2D/높이 방식.
- 경제 저장/상품 가격·소비량, 반응형 관계·신뢰, 실제 제작·거래, 음성 대화, NPC 가족/거주지, 몬스터, 공격 등은 구현하지 않음.
- 플레이어가 시장 재고를 조작할 수 없음. 세계가 움직인다는 첫 관찰용 사건만 구성함.
- **실제 Android GPU 프레임/온도/메모리·손가락 조작 지연 측정 미완료.** 소프트웨어 FPS를 실기기 성능이라고 주장하지 말 것.
