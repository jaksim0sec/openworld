# 카엘 항구 · 서쪽 선착장 첫 구획

개발 기준 2026-11-18. **부분 구현 및 아트 품질 미통과.** 기존 sky_grass_study_v1 및 Study 05 하늘/초원 코드를 삭제하거나 새 엔진으로 재작성하지 않았다.

## 구현
- 기존 맵의 구불구불한 하천 우안에 좁은 보행 구획 조성. 수정 지형은 항구 주변에서만 부드럽게 블렌딩됨.
- 경사진 연결로로 올라갈 수 있는 목조 부두, 선착장 말뚝·화물 상자·윈치 크레인·그늘 돛.
- 상점 2개, 수리공방, 창고. 각 건물은 처마가 돌출된 경사 지붕, 골조와 몰딩, 지붕기와, 창호, 차양, 램프, 돌기단, 출입 가능한 실제 벽 개구부와 실내 바닥을 갖춘 커스텀 메시.
- 접근 가능한 상점/작업장 실내, 작업대·선반·통·공구 모형. 실내 바닥과 출입 경사턱 연결.
- 8각 종탑과 2개 시장 차양을 거리의 시각적 랜드마크로 배치.
- 벽은 플레이어 반지름을 고려한 박스 충돌, 접근로에는 연속 바닥 높이 판정. 기존 고목 충돌도 유지.
- 근거리 E/조사 버튼으로 상점, 공방, 부두의 설명을 확인하는 최소 상호작용. 경제/퀘스트 보상은 아직 없음.

## 설계와 영향
- 새 파일 `harbor.js`: 순수 지오메트리·충돌·지형 사용량 정보와 1024px 절차적 페인터리 재질 아틀라스를 담당함.
- 기존 `scene.js`: 별도 건축 재질 셰이더/8번째 드로우콜과 구획 지형 배치만 추가, 원본 grass atlas/sky shaders 유지.
- 기존 `movement.js`: 사각형 벽 충돌/경사 입구/상호작용을 받아들이도록 소폭 확장.
- `index.html`: 항구 시점 추가, 원래 초원/숲/절벽 전환 유지.

## 검증
- `node --test tests/*.cjs`: 12건 통과. 건물 출입 개구부/벽 차단/층고/임계 충돌/메시 유한값 검증 포함.
- Chromium + Xvfb + ANGLE SwiftShader로 **실제 WebGL2** 시연 렌더: 데스크톱 640×390 CSS / 저해상도 내부 렌더 448×273, GL 오류 0, JS 오류 0, 걷기 확인. 약 278K 삼각형, 8 드로우콜. 소프트웨어 4~5FPS (실제 GPU 추정 불가).
- 모바일 에뮬레이션 CSS 360×690 / 내부 180×345(절전), GL 오류 0, JS 오류 0. 소프트웨어 3~6FPS (실기기 성능 아님).
- 상점 내부 디버그 텔레포트 진입 시 바닥 y=3.62, 상호작용 표시 확인. 실제 출입문 이동 단위 테스트 통과.

## 여전히 부족한 점
- 건축물 외관은 커스텀 세그먼트·지붕을 가진 시연 에셋이지만 레퍼런스의 최종 비주얼 수준에는 미달. 먼 곳에서 비슷한 형태의 집이 반복돼 보임. 완료된 아트 에셋이라고 간주하지 말 것.
- 도로, 상점 내부의 색상/표면 구조, 조명, 창문 세부 디테일, 부두의 물리적 연결을 추가 수작업 검수해야 함.
- 충돌은 2D 바닥 높이 + 사각형 벽/원형 고목에 국한됨. 계단, 다층 실내, 문 개폐, 배 탑승, 물 수영은 미구현.
- NPC/상업/주민 경제/길드/전투는 미구현. 자동화 WebGL 성능 테스트는 모바일 실기기 측정으로 대신할 수 없음.
