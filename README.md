# Serenvelt / 세른벨트

모바일 웹 오픈월드 RPG 프로젝트. 장기 목표는 자유 탐험, 생활형 NPC, 몬스터 생태계, 길드와 성장 시스템이 실제로 존재하는 따뜻한 하이 판타지 세계다.

## 개발 현황

**2026-11-18 현재 main: 환경 스터디 05 + 탐험 조작 01**. [시연](index.html) · [정적 검증](.github/workflows/verify.yml). 사회·전투 시스템은 아직 없다. **2단계 탐험 조작(1인칭 이동·카메라·지형 높이 충돌·점프·터치 입력)은 main에 통합**했다. 실제 모바일 실기기 성능 및 현재 환경 비주얼 품질 검증은 미완료다. 사용자 제공 지형·하늘·인체 모델과 지역 지도를 참고했다.

- 목표 아트: Painterly Stylized Realism + Anime-Stylized Environment
- 검증 대상: 대기 원근, 지형 곡면, 수목 실루엣, 잔디, 수면, 모바일 GPU 부하
- 완료 기준: 실제 모바일 실행과 스크린샷 대조, 성능 계측을 거친 뒤 다음 단계로 진입
- 금지: 원신/기타 게임 에셋 복제, 박스/구체 조합을 최종 모델로 취급, 구현 개수로 퀄리티를 평가

[1단계 설계](docs/superpowers/specs/2026-11-18-environment-study-design.md) · [개발 계획](docs/superpowers/plans/2026-11-18-environment-study.md)

## 기술 판단

3D 환경의 시각적 성공과 RPG 시스템 개발을 분리한다. 웹용 고급 렌더링에서 WebGL2가 폭넓은 호환성을 제공하고 WebGPU가 발전 중이지만, API를 많이 도입하는 것이 곧 더 좋은 풍경을 보장하지 않는다. 실제 병목과 미술적 결함을 먼저 측정한다.

현재 확인된 제약: SwiftShader 소프트웨어 렌더에서 WebGL2 시연은 실행했으나 원신/마비노기 모바일 수준의 아트 디렉션과 **실제 모바일 GPU 성능은 미검증**이다. 문법 검사나 소프트웨어 FPS를 완성 판정으로 간주하지 않는다.

## 현재 조작

- PC: WASD 이동, Shift 달리기, Space 점프, 마우스 드래그 시점, E 고목 조사
- 모바일: 왼쪽 조이스틱 이동, 오른쪽 화면 드래그 시점, 점프·조사 버튼
- '초원/숲/절벽' 버튼은 테스트용 순간 이동, 화질 버튼은 해상도·잔디 인스턴스량 조절
- [탐험 프로토타입 검증 기록](docs/exploration-stage02-verification.md)

현재 충돌은 지형 높이와 **시연용 고목 한 개**의 원형 충돌체만 처리한다. 건축물, 수중, 전투, NPC와의 충돌은 미구현이다.

## 카엘 항구 · 서쪽 선착장 (첫 구현 구획)

- **새로운 기본 시작 시점은 카엘 항구**다. 시험용 초원·숲·절벽 시점은 보존한다.
- 부두·경사 연결로·수리공방·상점·창고·8각 종탑·시장 차양, 상점 실내·벽 충돌, 간단한 E 조사 구현.
- [개발/검증 및 미완료 항목](docs/kael-harbor-slice.md). **모바일 실기기 FPS 및 최종 아트 품질은 미통과**다.
- HTML 로더는 `harbor.js → movement.js → scene.js` 순서. 배포는 루트 `index.html`을 그대로 제공한다.

## 카엘 항구 주민 생활 V1

- 6명 역할별 주민(선적 담당·운반원·상인·수리공·길드 서기·순찰대원)의 **플레이어 독립 일과/이동/작업·대화** 구현.
- 운반·상담·수리·순찰 애니메이션과 공통 주민 모델 인스턴싱. 화물 입항 지연→정오 시장 입고→야간 마감 상태가 물품 위치와 대화에 반영됨.
- 가까운 주민에게 E/조사, NPC 몸체 회피, 모바일 터치 입력 지원. 기존 항구와 초원·수목·지형 충돌 유지.
- [구현 및 검증 기록](docs/kael-harbor-social-v1.md) / [생활형 세계 설정 초안](docs/world/SERENVELT_WORLD_BIBLE_v0.1.md).
- 테스트: Node 19개 통과, Chromium WebGL2 소프트웨어 렌더 0 오류, 모바일 에뮬레이션 조이스틱/대화 확인.
- **V1 공통 모델은 최종 아트 에셋이 아니며 실제 Android GPU 성능/메모리는 미검증.** 가격·거래·관계 저장 시스템도 아직 없음.
